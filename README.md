A one-image summary of 18 November 2026 world news: big headline blocks, small subheads and source lines laid out on a clear front-page grid, rendered to 1920x1080 (16:9).

## Run it

```sh
python3 main.py
```

Writes `build/news-image-20261118.png`.

## Files

- `main.py` — renders the front page from `build/src.html` with Playwright
- `build/src.html` — the front-page layout (masthead, stat strip, lead story, four cards)
- `build/news-image-20261118.png` — the final 1920x1080 image entered on make.fun

Headlines compiled from Reuters, AP, BBC, Al Jazeera, AFP, NASA and UN News wire snapshots for the day. Contested claims attributed to the party making them.
